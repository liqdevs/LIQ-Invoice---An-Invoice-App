# LIQ Invoice Public Release

This folder is ready to push to GitHub as a public repository for the app release.

## Included
- Signed installer in `public_download/`
- EULA and checksum
- App source files and build spec
- GitHub Pages site files in `docs/`
- Ko-fi support button included in README and docs

## Publish steps
1. Create a new repository on GitHub.
2. Push this folder as the repo root.
3. Enable Pages from the `main` branch and `/docs` folder.
