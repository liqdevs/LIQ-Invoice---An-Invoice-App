# LIQ Invoice Public Release Guide

This folder contains the public release assets for LIQ Invoice.

## Files
- `public_download/LIQ Invoice Installer.exe` — signed installer
- `public_download/EULA.txt` — license agreement shown during install
- `public_download/LIQ_Invoice_Installer.sha256` — SHA256 checksum file
- `public_download/README.txt` — user instructions for verification

## Distribution
Use GitHub Releases or another trusted host to publish the installer.

### Recommended GitHub release process
1. Create a new repository for LIQ Invoice.
2. Add these files and push the repo.
3. Create a GitHub release and attach `public_download/LIQ Invoice Installer.exe`.
4. Share the release URL in your Ko-fi description.
